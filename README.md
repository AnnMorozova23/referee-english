# Referee English: как запустить приложение в Telegram

В архиве лежат файл `index.html` (само приложение) и папка `audio` (60 аудиофайлов). Чтобы Telegram мог открыть приложение, его нужно разместить в интернете по адресу с https. Это бесплатно и займёт около 10 минут.

## Шаг 1. Разместить приложение в интернете (Netlify, бесплатно)

1. Распакуйте архив. Получится папка `referee-english`, внутри неё `index.html` и папка `audio`.
2. Зайдите на https://app.netlify.com/signup и зарегистрируйтесь (проще всего через Google или GitHub).
3. Откройте https://app.netlify.com/drop.
4. Перетащите **всю папку** `referee-english` в окно браузера.
5. Через полминуты появится адрес вида `https://cheerful-name-12345.netlify.app`. Откройте его: приложение должно загрузиться.
6. По желанию: Site configuration → Change site name, например `referee-english-anna`. Тогда адрес станет `https://referee-english-anna.netlify.app`.

> Если позже обновите файлы приложения, зайдите в сайт на Netlify → Deploys и снова перетащите папку.

## Шаг 2. Создать бота, который будет открывать приложение

Бот нужен только как «дверь» в приложение. Он ничего не пишет и не присылает напоминаний.

1. Откройте в Telegram **@BotFather** и отправьте `/newbot`.
2. Придумайте имя, например `Referee English`.
3. Придумайте username, он должен заканчиваться на `bot`, например `anna_referee_english_bot`.
4. Отправьте `/mybots` → выберите бота → **Bot Settings** → **Menu Button** → **Configure menu button**.
5. Отправьте адрес из шага 1 (например, `https://referee-english-anna.netlify.app`).
6. Отправьте название кнопки, например `English`.

Готово. Откройте своего бота: слева от поля ввода появится кнопка **English**, она открывает приложение. Бота можно закрепить в списке чатов, чтобы он всегда был под рукой.

## Как сохраняется прогресс

- Внутри Telegram прогресс хранится в облаке Telegram (CloudStorage), поэтому он не пропадёт при смене телефона.
- Если открыть приложение просто в браузере, прогресс сохранится только в этом браузере.
- В разделе «Прогресс» есть кнопка «Резервная копия»: она копирует код, которым можно восстановить прогресс.

## Что внутри

- 20 уроков (каждый можно проходить несколько дней — шаги сохраняются отдельно). В каждом уроке:
  - 10 терминов из Futsal Laws of the Game 2025-26 и 10 слов или фраз уровня B2–C1 на каждый день, у каждого озвучка и пример (всего 400);
  - проверка слов;
  - грамматика уровня B1: подробное объяснение на русском (образование, употребление, исключения, типичные ошибки, примеры с переводом) и 10 упражнений;
  - чтение: адаптированный текст по одному из правил (Law), с озвучкой и переводом терминов по нажатию;
  - аудирование: диалог (судейская ситуация или бытовая) с вопросами и текстом, который подсвечивается во время прослушивания.
- Повторение слов с интервалами: 1, 2, 4, 7, 14, 30, 60 дней.
- Словарь с поиском и раздел «Прогресс».

Тексты для чтения адаптированы до уровня B1 на основе официальных правил. Если нужна точная формулировка правила, сверяйтесь с оригинальным текстом Laws of the Game.
